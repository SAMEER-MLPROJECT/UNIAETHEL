# Dataset
All captures are synthetic, generated by `scripts/generate_demo_data.py` (deterministic seeds) and listed in
`data/MANIFEST.yaml` (file, split, scenario, seed, class, host, ground-truth interval, parameters, direction).
Background: 18 workstations (web-like browsing, DNS, 30 s NTP-like, 64 s telemetry, 15 s API polling, file share), a public
web server with external clients, DNS and file servers. Events: C2 (period, jitter), recon (growing rate, cyclic sweep),
DDoS (many-to-one ramp), exfil (sustained single connection or chunked), unknown DNS-tunnel-like bursts, and benign look-alikes:
heartbeat, new telemetry agent, fast API polling (C2-like); inventory sweep, app restart (recon-like); flash crowd, load test
(DDoS-like); backup, cloud sync, software update (exfil-like).
Splits: train 6 normal; val 2 normal + attacks (2 seeds) + 4 look-alikes; test 2 normal + held-out variants/seeds + unknown +
10 look-alikes; demo 5; sweeps 50. Writers: Scapy (reference) and a fast header-only writer (snap length 96, true
lengths kept); the test suite checks both produce identical parsed traffic.
